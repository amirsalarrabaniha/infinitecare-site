# Infinite Care Beauty Clinic – redesigned static site

Static HTML/CSS/JS rebuild of https://www.infinitecare.hu (Home, Our treatments, Our prices + Offers/packages section), using the original images and fonts (Montserrat, Playfair Display, Mr Dafoe via Google Fonts) with a new design and animations.

- `index.html`, `services.html`, `prices.html` – pages (generated by `build.py` from shared header/footer; price list data in `data/prices.txt`)
- `css/style.css`, `js/main.js` – styles and vanilla-JS animations (loader/page transitions, word-split headings, scroll reveal, parallax, counters, tilt, mobile menu)
- `assets/images/` – original images

No build step needed: open `index.html` or deploy to GitHub Pages (relative paths only). Edit content, then run `python3 build.py` to regenerate pages.
